## 🌐 Option A: Build a Portfolio Website

A portfolio beats a resume — it *shows* rather than *tells*.

| Method | How it works | Best for |
|---|---|---|
| ⭐ **Prompt-based generation** *(Recommended)* | Describe yourself — experience, skills, projects, contact info — or paste your GitHub README / LinkedIn bio directly into the portfolio builder prompt. | Fastest path from zero to live site |
| 🔗 **Import from GitHub README** | Copy-paste your existing `README.md` profile content straight in. | Devs who already maintain a GitHub profile README |
| 💼 **Import from LinkedIn** | Paste your LinkedIn "About" + experience sections. | People with an up-to-date LinkedIn but no formatted resume |
| 📄 **LinkedIn resume export** | Use LinkedIn's built-in "Save to PDF" feature under your profile to get a baseline resume. | A quick, no-frills starting document |

> 💡 **Tip:** Even a rough prompt like *"I'm a frontend dev, 2 years experience, know React + Tailwind, built 4 projects, want a clean minimal portfolio"* is enough to get a strong first draft.

## 📝 Option B: Generate a Resume Fast

If you specifically need a **traditional resume document** (PDF/Word), these tools have solid free tiers:

| Tool | Link | Free tier highlights |
|---|---|---|
| **FlowCV** | [flowcv.com](https://flowcv.com/) | Clean templates, unlimited PDF exports on free plan |
| **Novoresume** | [novoresume.com](https://novoresume.com/) | ATS-friendly templates, strong content suggestions |
| **Enhancv** | [enhancv.com](https://enhancv.com/) | Modern designs, guided content prompts |

⚠️ *Advanced templates, extra downloads, or premium sections may require a paid upgrade — the free tiers are usually enough to get a solid first version out the door.*

## 💎 Bonus: Level Up Your GitHub Profile

Your GitHub *is* a living resume. A few high-leverage habits:

- ✅ Keep your **profile README** updated with current projects, stack, and what you're learning
- ✅ Pin your **best 4–6 repos** — quality over quantity
- ✅ Write real `README.md` files for your projects (what it does, why, how to run it)
- ✅ Commit consistently — a green graph tells a quiet, credible story
- ✅ Add a short bio + working contact link (portfolio site, email, or LinkedIn)

## 🏆 Golden Rules

1. **Build in public.** Ship small projects often — momentum beats perfection.
2. **Show, don't tell.** A live link outperforms a bullet point every time.
3. **Keep it current.** An outdated portfolio hurts more than no portfolio.
4. **One clear CTA.** Make it obvious how someone contacts or hires you.
5. **Build every day.** Consistency compounds.
